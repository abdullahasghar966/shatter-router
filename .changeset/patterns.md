Seven new fracture patterns, each loaded on first use: `radial` (a windscreen spider web), `rings`, `triangles`, `hex`, `bricks`, `tiles` and `strips`. Pick one in a composition (`effect: { motion: 'explode', pattern: 'hex' }`) or with `ShatterEffect.pattern`. `EffectSource` is now exported (the React adapters' declarations referenced it).
