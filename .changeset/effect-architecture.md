Effects are lazy plugins: the engine core is 11.5 kB gzip (was 20 kB) and each built-in effect and the `impact` fracture pattern load on first use, prefetched for the default effect and a link's own effect. Effects can be composed from parts, `{ motion, pattern, material, stagger, timing }`, wherever an effect is accepted, and registered by name. New `stagger` orders (`'radial'`, `'linear'` with an angle, `'spiral'`, `'random'`, `'reading-order'`) reach effects as `ctx.order` and GLSL `shard.order`.
